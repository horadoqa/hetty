# hetty

Ferramenta open-source, distribuído como um único binário Go e pode atender muito bem diversos fluxos de pentest e bug bounty.

O Burp Suite Professional custa US$ 475 por ano por licença.

Um engenheiro de software em Amsterdã criou uma alternativa open-source e disponibilizou gratuitamente no GitHub.

Hoje o projeto já ultrapassa 10 mil estrelas.

O nome da ferramenta é:

⚡ Hetty


Para quem trabalha com:

• Pentest Web
• Bug Bounty
• Segurança de APIs
• Auditoria de aplicações

O fluxo principal normalmente é sempre o mesmo:

- interceptar requests
- analisar responses
- modificar payloads
- reenviar requisições
- validar comportamentos

Esse é exatamente o problema que o Hetty resolve.


## O que ele oferece?

- Proxy MITM HTTP/HTTPS
- Interceptação de requests e responses
- Replay de requisições
- Busca avançada
- Organização por escopo
- Projetos independentes
- Interface Web moderna
- API GraphQL

Tudo distribuído como um único binário em Go.

## Tecnicamente falando

O Hetty não tenta competir com todos os recursos corporativos do Burp Suite.

Não possui o mesmo nível de automação, scanners avançados ou ecossistema de extensões.

Mas cobre muito bem aquilo que muitos profissionais utilizam diariamente:

- proxy
- intercept
- replay
- análise manual


## O que mais me chamou atenção

A história por trás do projeto.

Enquanto muitas ferramentas seguem o modelo SaaS e assinatura recorrente, um desenvolvedor decidiu construir uma alternativa open-source para um dos workflows mais importantes da segurança ofensiva.

E a comunidade respondeu.

Mais de 10 mil estrelas mostram que existe demanda por ferramentas abertas, simples e acessíveis.

Nem toda inovação vem de uma big tech.

Às vezes ela vem de um único desenvolvedor resolvendo um problema real.
